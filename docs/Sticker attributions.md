# Sticker attributions

Each Flaticon pack maps **one-to-one** to a folder under `public/assets/stickers/`. The editor catalog lives in `src/lib/yearbook/sticker-catalog.ts` (`STICKER_ATTRIBUTION_MAP`).

## Folder mapping (legacy → current)

| Slug (folder) | Pack title | Legacy folder(s) |
|---------------|------------|------------------|
| `university` | University | `university/` (space icons moved out) |
| `best-friend` | Best friend | `friendship/` |
| `flowers` | Flowers | `spring2/` |
| `night-party` | Night party | `night-party/` |
| `pinata` | Piñata | `birthday/` |
| `school` | School | `education/` + `graduation/` |
| `nature` | Nature | `nature/` |
| `flower` | Flower (Anna Kuba) | `spring/` |
| `gift` | Gift | `gift/` |
| `dessert` | Dessert | `dessert/` |
| `solar-system` | Solar system | `solar system/` + planet/alien/rocket from `university/` |
| `oops` | Oops (Prosymbols Premium) | `Prosymbols Premium/` |
| `shiba-inu` | Shiba inu | `shiba-inu/` |
| `unicorn` | Unicorn | loose `unicorn*.png` at stickers root |
